# ChronicleDB

ChronicleDB is a Go project intended to become a technically serious
distributed transactional database and distributed-systems engineering
project.

Current maturity: **INITIALIZED**

The repository is intentionally at Day Zero. No storage-engine,
transaction, MVCC, replication, Raft, SQL, or distributed-database
implementation is claimed yet.

The next milestone is **Architecture Foundation**.

Implementation must not begin until the Architecture Foundation has been
reviewed and accepted.

See `docs/`.
